# Smart Student Marks Analyzer

A Python-based web application that helps users manage student marks and analyze academic performance.

## Live Demo
https://student-marks-analyzer-ah3j.onrender.com

## GitHub Repository
https://github.com/jagadesh181105/student-marks-analyzer

## Features
- Add and manage student marks.
- Automatically calculate total marks and average.
- Generate grades and Pass/Fail results.
- View student performance using interactive charts.
- Search student records by name.
- Download student performance reports as PDF.

## Technologies Used
- **Programming Language:** Python
- **Backend Framework:** Flask
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite
- **Charts:** Chart.js
- **PDF Reports:** ReportLab
- **Deployment:** Render

## How to Run Locally
1. Clone this repository.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `python app.py`
4. Open your browser and visit:
   `http://127.0.0.1:5000`
